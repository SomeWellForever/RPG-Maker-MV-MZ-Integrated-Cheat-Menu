# macOS graphical installer (test build)

Double-click **Install SWF Cheat Menu.app** and select your RPG Maker MV/MZ game folder. To uninstall, double-click **Remove SWF Cheat Menu.app**. No Terminal, Python, or manual executable permission changes required.

Both apps include the native installer and select Apple Silicon or Intel automatically. The installation and migration logic is the same as the Windows/Linux binary.

**macOS Gatekeeper:** This preview is ad-hoc signed, not Apple Developer ID notarized. macOS may block the app as an unidentified developer; if so, open System Settings → Privacy & Security → Open Anyway (no Terminal required). A notarized, seamless first launch requires Apple Developer ID credentials.

Keep Xenolauncher's built-in Cheat Menu disabled. Always save games in a separate slot when testing a mod.

# Установщик macOS без Терминала

Дважды нажмите **Install SWF Cheat Menu.app**, выберите папку игры RPG Maker MV/MZ. Для удаления используйте **Remove SWF Cheat Menu.app**. Ввод команд, установка Python или изменение прав вручную не нужны.

**Важно:** тестовая сборка подписана локально, но не нотарифицирована Apple. При предупреждении об неизвестном разработчике воспользуйтесь «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

В Xenolauncher встроенную опцию Cheat Menu необходимо выключить.
