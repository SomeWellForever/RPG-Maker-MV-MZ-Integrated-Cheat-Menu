## 🇷🇺 Русский

Объединённый чит-мод для одиночных игр на RPG Maker MV/MZ. Один `Cheat_Menu.js`, один чит-предмет и быстрый оверлей.

### Основные возможности
- Управление уровнем, опытом, HP/MP/TP, характеристиками и навыками персонажей.
- Выдача предметов, оружия и брони; лимиты стопок: стандартный, 99, 999 или 9999.
- Телепортация, сохранённые точки, проход сквозь стены и скорость передвижения.
- Изменение золота, переменных и переключателей.
- Боевые функции, включая управление HP противников и мгновенную победу.
- Оверлей на клавише `1` и единое меню на `F7`, в том числе во время боя.

### Что изменилось в v2.1
- Оверлей `1` и чит-предмет доступны во время боя.
- Функции старого Cheat Menu распределены по основным разделам без дубликатов.
- При открытии из боевого инвентаря предмет не должен расходовать ход.
- Сохранённые позиции и настройки скорости доступны в основном меню.

### Установка
1. Сделайте резервную копию сохранений и закройте игру.
2. Распакуйте установочный ZIP рядом с `Game.exe`.
3. Запустите `Install_Windows.cmd` (Windows) или `bash Install_Linux.sh` (Linux; нужен Python 3).
4. Проверьте работу на отдельном сохранении.

**Ограничения:** Совместимость с нестандартными плагинами не гарантирована. Используйте на свой риск и храните резервные копии. Полноценная проверка каждой игры не проводилась.

## 🇬🇧 English

An integrated cheat mod for single-player RPG Maker MV/MZ games. One `Cheat_Menu.js`, one in-game key item, and a quick overlay.

### Features
- Edit actor levels, EXP, HP/MP/TP, stats, and skills.
- Add items, weapons, and armor; choose default, 99, 999, or 9999 stack limits.
- Teleport, use saved locations, toggle no-clip, and change movement speed.
- Edit gold, game variables, and switches.
- Battle cheats including enemy HP controls and instant victory.
- Open the overlay with `1` or the integrated menu with `F7`, including in combat.

### What's new in v2.1
- The `1` overlay and key-item menu can now be accessed in battle.
- Legacy Cheat Menu functions are incorporated into the main menu without duplicate categories.
- Opening the item from battle inventory is designed not to consume a turn.
- Saved locations and movement-speed settings are accessible from the main menu.

### Installation
1. Back up saves and close the game.
2. Extract the release ZIP next to `Game.exe`.
3. Run `Install_Windows.cmd` (Windows) or `bash Install_Linux.sh` (Linux; Python 3 required).
4. Test using a separate save slot.

**Limitations:** Compatibility with custom plugins is not guaranteed. Keep backups. Not all games have been tested.
