# Changelog / История изменений

## v2.1 — Battle Update / Обновление боевого меню

**Русский:**
- Быстрый оверлей (`1`) доступен в бою.
- Чит-предмет и основное меню доступны в бою.
- Существующая функция мгновенного уничтожения противников сохранена.
- В основном меню добавлены управление HP врагов и мгновенная победа.
- Удалена отдельная вкладка с повторяющимися читами, функции распределены по разделам.
- Поддержка сохранённых позиций и настроек скорости перенесена в основное меню.

**English:**
- Legacy quick overlay (`1`) is accessible during battles.
- Main menu and control item can be opened during battle.
- Existing instant enemy defeat action remains available.
- Battle menu includes enemy HP controls and instant victory.
- Removed the duplicate extra-cheats tab; features are organized across main sections.
- Saved positions and speed settings are also accessible in the main menu.

## v2.0 — Integrated release / Объединённая версия

- Combined legacy Cheat Menu and the universal control item into one `Cheat_Menu.js` plugin.
- Added a unified menu, key-item entry, `F7` shortcut, inventory stack-limit selection, and map/actor editing.
- Объединение прежнего Cheat Menu и универсального чит-предмета в один JavaScript-файл.
